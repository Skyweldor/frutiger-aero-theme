# Changelog

## Unreleased

- New **Frutiger Aero (Night)** color theme: midnight navy, moonlit cyan and dim teal.
- New **Night Wallpaper + Full Glass** mode, with a CSS moonlit sky fallback until you add `assets/frutiger-aero-night-wallpaper.jpg`.
- `npm run build:embed` now generates both wallpapers; disabling glass restores your previous `window.controlsStyle`.

## 1.0.0

- Two color themes: **Frutiger Aero (Daylight Glass)** and **Frutiger Aero (Deep Aqua)**.
- **Frutiger Aero: Enable Glass Mode** command with three modes: Scenic Wallpaper + Full Glass, Pure CSS Mesh & Orbs, and Minimal Glass Chrome.
- See-through glass for the sidebar, editor, bottom panel and secondary sidebar, including VS Code's "modern UI" floating panels.
- Aero-style title bar: frosted caption, glowing title text, glass caption buttons and blue orb Back/Forward buttons.
- Readable dark-aqua menus and pickers.
- **Frutiger Aero: Disable Glass Mode** command that removes everything the enable command set.
- High-contrast I-beam mouse pointer over code and a soft glow on the typing caret.
- Pale aqua links that stay readable over the wallpaper, and a soft text shadow on the Welcome page.
